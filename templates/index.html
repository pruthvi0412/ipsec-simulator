Introduction to IPsec & Digital Signatures

Internet Protocol Security (IPsec) is a secure network protocol suite that authenticates and encrypts the packets of data to provide secure encrypted communication between two computers over an Internet Protocol network.

This simulator focuses on the integration of symmetric encryption (for confidentiality) and asymmetric digital signatures (for authentication and integrity) within an IPsec Security Association context.

🎯

Experiment Objective

The primary objectives of this experiment are:

  • To understand the concept of a Security Association (SA) and its role in IPsec.
  • To implement a simulation model of symmetric key cryptography (AES-256) for data confidentiality.
  • To integrate RSA digital signatures to guarantee data authenticity and non-repudiation.
  • To practically observe how digital signatures detect packet tampering (Man-in-the-Middle attacks).
📚

Theoretical Background

Security Association (SA)

An SA is a simplex logical connection that provides security to the data carried by it. It is uniquely identified by a Security Parameter Index (SPI), an IP Destination Address, and a security protocol identifier.

Symmetric Encryption (AES-256-CBC)

Advanced Encryption Standard (AES) is a symmetric block cipher chosen by the U.S. government to protect classified information. In CBC (Cipher Block Chaining) mode, each plaintext block is XORed with the previous ciphertext block before being encrypted.

Digital Signatures (RSA-PSS-SHA256)

A digital signature is a mathematical scheme for verifying the authenticity of digital messages or documents. A valid digital signature gives a recipient strong reason to believe that the message was created by a known sender and that the message was not altered in transit.

Source Code

Core cryptographic algorithms used in the simulation

def encrypt(sa, text):
    iv = os.urandom(16)
    data = text.encode()
    pad = 16 - len(data) % 16
    data += bytes([pad]) * pad
    
    # Encrypt Data
    e = Cipher(algorithms.AES(sa["enc_key"]), modes.CBC(iv)).encryptor()
    cipher = e.update(data) + e.finalize()
    
    # Digitally Sign Data
    sig = sa["private_key"].sign(
        iv + cipher,
        padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
        hashes.SHA256()
    )
    return iv, cipher, sig

def decrypt(sa, iv, cipher, sig):
    # Authenticate Data (Verify Signature)
    sa["public_key"].verify(
        sig, iv + cipher,
        padding.PSS(mgf=padding.MGF1(hashes.SHA256()), salt_length=padding.PSS.MAX_LENGTH),
        hashes.SHA256()
    )
    
    # Decrypt Data
    d = Cipher(algorithms.AES(sa["enc_key"]), modes.CBC(iv)).decryptor()
    data = d.update(cipher) + d.finalize()
    pad = data[-1]
    return data[:-pad].decode()
